# Client

The Manhunt PWA — **React 19 + Vite**, with `vite-plugin-pwa` (installable,
offline app shell) and one **WebSocket per Game** to the backend. It hosts the
lobby (create/join, roles, ready, start), GPS capture, the in-match **MapLibre
GL** map — the player's own pin, permitted others from the Game's fan-out, and
the play-area boundary overlaid — and the game-over screen.

## Scripts

Run these from the repo root (they are root workspace scripts):

```bash
npm run dev          # Vite dev server on :5173, with the Worker in local workerd
npm run build        # build the PWA into dist/ and the Worker into dist-worker/ (repo root)
npm run test:client  # Vitest component tests (jsdom) — client suite only
npm run test:e2e     # Playwright end-to-end tests
```

Root `npm test` runs the backend and client suites together. From inside
`client/` you can also run the workspace's own scripts directly (`npm run dev`,
`npm run build`, `npm test`, `npm run test:e2e`).

`@cloudflare/vite-plugin` runs the Worker from `deploy/wrangler.jsonc` in local
`workerd` for both `dev` and `build`, so development talks to exactly the backend
production runs — same origin, no proxy and no separate server to start. Creating
a Game is `POST /api/games`, joining `POST /api/games/join`, and the Lobby then
follows the Game over `/ws/games/:gameId`. The Seat's `{ gameId, playerId }` is
kept in `localStorage`, so a reload reconnects to the same Seat.

## Layout

```text
client/
├── index.html            # app entry
├── vite.config.ts        # Vite + Cloudflare + PWA + Vitest config
├── playwright.config.ts  # e2e config (e2e/build.ts builds first)
├── public/               # PWA icons (generated by scripts/gen-icons.py)
├── scripts/gen-icons.py  # regenerates the icons (requires Pillow)
├── src/
│   ├── main.tsx          # React root + service-worker registration
│   ├── App.tsx           # landing shell hosting the Lobby
│   ├── lobby/useLobby.ts # create/join over HTTP, then follow the Game's socket
│   ├── transport/        # the Game's WebSocket: frames, request/reply, close codes
│   └── test/setup.ts     # Vitest + jest-dom setup
└── e2e/                  # Playwright specs, against the built Worker in workerd
```

## Icons

The PWA icons in `public/` are generated pixel art (red diamond + rings on the
dark theme). Don't hand-edit the PNGs — tweak `scripts/gen-icons.py` and run
`python3 scripts/gen-icons.py` (requires `pip install Pillow`).
